Tentang Project

Apa itu FruReka AI?

FruReka AI adalah prototype website yang dikembangkan untuk mendeteksi jenis buah dan kondisi kesegarannya menggunakan metode Convolutional Neural Network. Sistem ini menggunakan model MobileNetV1 dengan konsep transfer learning.

Website ini dapat mengenali tiga jenis buah, yaitu apple, banana, dan orange. Setiap buah akan diklasifikasikan ke dalam kondisi segar atau busuk berdasarkan citra yang diunggah oleh pengguna.

Teknologi

Teknologi yang Digunakan

Website ini menggabungkan klasifikasi citra dengan CNN, model MobileNetV1, dan implementasi web menggunakan Flask.

Dataset Buah

Dataset terdiri dari enam kelas, yaitu freshapples, freshbanana, freshoranges, rottenapples, rottenbanana, dan rottenoranges.

Model CNN

CNN digunakan untuk mengenali pola visual pada gambar buah, seperti warna, bentuk, tekstur, bercak, dan permukaan buah.

Website Flask

Flask digunakan untuk menghubungkan model deep learning dengan tampilan website agar hasil prediksi dapat dilihat oleh pengguna.

Fitur

Fitur Utama

FruReka AI dirancang dengan fitur sederhana untuk mendukung proses deteksi jenis buah dan kondisi kesegarannya.
